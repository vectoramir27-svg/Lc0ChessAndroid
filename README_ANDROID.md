# 📱 Lc0 Chess Overlay — Нативный Android Ассистент для Chess.com

Нативное Android-приложение на Kotlin для игры через официальное мобильное приложение **Chess.com** из Google Play.

---

## 🚀 Архитектура и принцип работы (Вариант А)

1. **Прозрачный оверлей (Pass-Through):**
   - Холст для рисования стрелок использует флаг `FLAG_NOT_TOUCHABLE | FLAG_NOT_FOCUSABLE`.
   - Все ваши касания, свайпы и перемещения фигур проходят насквозь в официальное приложение Chess.com без малейшей задержки.

2. **Мощность RTX 5060 по локальному Wi-Fi:**
   - Телефон не греется и не тратит батарею на тяжелые нейросети.
   - Кадр доски сжимается в JPEG и отправляется на ПК (`http://192.168.1.108:8765/analyze_image`).
   - ПК через ONNX распознает расстановку фигур и запускает Lc0 на GPU RTX 5060 с анти-детект фильтром (1900-2400 Elo).

3. **Визуализация и Голос:**
   - На экране телефона прямо поверх шахматной доски появляется неоновая стрелка хода (`#00FF88`).
   - Синтезатор речи (TTS) озвучивает ход на русском языке (например: *«Конь эф 3 на дэ 4»*).
   - Кнопка `⚪` / `⚫` переключает ориентацию доски для игры за белых или черных.

## 🛠 Как собрать APK и установить на телефон

### Способ 1: Через Android Studio (Рекомендуемый)
1. Скачайте и установите бесплатную [Android Studio](https://developer.android.com/studio).
2. Запустите Android Studio и выберите **Open**, указав папку:
   `c:\Users\user\Downloads\шахматы\Lc0ChessAndroid`
3. Подключите Android-смартфон к компьютеру по USB-кабелю (в настройках телефона включите «Отладка по USB»).
4. Нажмите зеленую кнопку **Run ▶** в верхней панели — APK автоматически скомпилируется и установится на ваш телефон!
5. Либо выберите в меню: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** — готовый файл `app-debug.apk` появится в папке `app/build/outputs/apk/debug/`. Его можно просто перекинуть на телефон и нажать «Установить».

### Способ 2: Через командную строку (Gradle)
Если у вас установлен Gradle или Android SDK:
```bash
cd c:\Users\user\Downloads\шахматы\Lc0ChessAndroid
./gradlew assembleDebug
```

## 🎮 Инструкция по использованию

1. **Запуск сервера на ПК:**
   - Убедитесь, что на ПК запущен `web_server.py` (или ярлык на рабочем столе `Lc0 Chess Studio`).
   - Телефон и компьютер должны быть подключены к одной Wi-Fi сети.

2. **Запуск на телефоне:**
   - Откройте приложение **Lc0 Chess Overlay**.
   - Введите IP вашего ПК: `192.168.1.108:8765` (уже стоит по умолчанию).
   - Нажмите **«Проверить связь»** -> статус станет зеленым: `● Связь с RTX 5060 установлена!`.
   - Нажмите **«Выдать разрешение»** -> включите переключатель «Показывать поверх других приложений».
   - Нажмите **«Запустить ассистент»** -> подтвердите разрешение на захват экрана.

3. **Игра в Chess.com:**
   - Откройте официальное приложение **Chess.com**.
   - На экране появится компактный виджет: `[♟ Lc0 | Готов | ⚪ | ⚡ Скан | ✕]`.
   - Если играете за черных — нажмите `⚪`, она сменится на `⚫` (доска инвертируется).
   - Нажмите **«⚡ Скан»** — на доске моментально загорится стрелка лучшего хода, а голос подскажет ход в наушники или динамик!
   - Виджет можно перетаскивать пальцем за иконку `♟ Lc0` в любое удобное место экрана.
